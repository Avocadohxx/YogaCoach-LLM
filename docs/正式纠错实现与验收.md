# 正式纠错实现与验收

在线生效规则由 knowledge/rules_manifest.json 指定；环境变量可覆盖路径。山式使用已有已审核 B 配置，仅允许举臂保持；侧弯仍为草案，保持门控。比较器默认的旧 draft 文件供原有实验复现，不作为在线默认入口。

默认山式肘规则：小于 165° 连续 1500ms 确认；进入 168°–180° 区间并保持 700ms 清除；最大帧间隔 500ms。本轮未为吞吐放宽阈值。它们是项目配置，不是通用人体标准。明显双臂下垂但声明举臂时，仅拒绝阶段不匹配，不凭几何桶认证正确阶段。

低质量、必需点出画、过期图像、无关模型或缺失上下文会中断证据。中断不能记录为改善。所有正式事件由服务器写入；客户端不能用 feedback_allowed=true 伪造历史。原始导入仅供显式隔离测试。

证据缓存保留完整快照匹配，按会话维护最新帧索引；返回前再次检查选中 event_id。每事件只提醒一次，纠错之间有十秒冷却。LLM 失败回到受控模板，不允许自由输出新的动作要求。历史关注提示仅依据同用户、同动作、已完成会话内的服务器规则事件。

验证层次：

1. 单元/组件回归：计时、冻结帧、来源、重试、阶段、规则版本、证据篡改和生命周期。
2. 真实模型冒烟：加载 LFS 权重，实际参考图输出 133 点。
3. 本地性能：准备阶段重复图像请求，报告样本量和 p50/p95；不能当作浏览器帧率。
4. 人工验收：实际摄像头、视频控制、不同设备、真实阶段与偏差标注。
5. 效果评估：真实输出与人工标签齐备后计算指标，参考/测试片段分离，保留失败案例。

目前不生成或手填真实准确率；审核状态不等同于已验证教学效果。模型文件 SHA256、来源文件校验和自动回归不能替代后两层。
