# C 工作说明：实时纠错、LLM 建议与练习总结

本文记录 C 与前端、规则和记忆模块的当前本地联调实现。C 接收服务端确认的姿势偏差，组织安全建议并记录反馈；不会让 LLM 直接从摄像头图像判断动作。

## 本次完成的内容

### 实时提示链路

1. 浏览器采集摄像头或视频帧，发送到本机后端 `/api/pose/frame`。
2. 后端使用 `data/models/rtmw_x_384.onnx` 提取 COCO-WholeBody 133 点，按启用规则计算角度与其他特征。
3. 山式举臂保持下，左右肘角低于规则触发范围并持续达到门限后，才建立可纠错事件。
4. C 验证事件仍是服务器当前有效证据，读取规则和会话上下文，再向 LLM 提交精简的测量摘要。
5. LLM 返回结构化建议后，后端检查目标部位和事件类型；如果模型不可用或回复不合规，则回退到固定安全话术。前端把结果显示在“本次提醒”。

本次针对“角度明显偏离但没有实时建议”的阻断做了调整：

- 肘部规则的最大帧间隔从 500 毫秒改为 1.5 秒，以适应浏览器等待本机 CPU 推理后再发送下一帧的节奏。持续偏差仍需满足规则的 1.5 秒时长门限。
- 不再因一帧推理处理超过 2 秒而直接重置整段证据；按帧时间戳和规则帧间隔判断证据是否连续。
- 关键点质量按规则实际依赖的测量判断。脚踝未入镜不会再拦截可用的肘部角度；双肩、肘、腕仍须清楚且在画面内。
- 证据尚不足时，前端尽量说明正在确认持续偏差、需要调整取景、视角不支持或模型不匹配等原因。

### 练习总结与页面呈现

结束真实练习时，服务器总结现在综合两类信息：

- **确认的姿势偏差**：按偏差类型和方向汇总次数，例如左侧和右侧持续肘部弯曲。
- **练习期间实际显示的提示**：汇总提示次数，并分为偏差纠正、镜头与观察、其他练习提示；每类列出出现最多的最多两条提示及次数。

练习记录卡片显示每次已保存的总结；结束本次练习后，“服务器总结”显示刚生成的总结。结束练习不会再把右侧最后一条有效建议覆盖成“练习已结束”。

未记录到可信偏差时，总结仍会明确说明“未记录到姿态偏差片段”，并保留本次总体提示；这不表示动作完全标准。旧的已保存总结不会自动重算，新格式从重启后结束的新练习开始生效。

## LLM 的输入边界

确认偏差后才请求 LLM。传入内容包括动作、目标部位、偏差类型、实测值、单位、规则范围、阶段和持续时间等。**摄像头图像、原始 133 点关键点、会话 ID 和历史记忆不会发送给 LLM。**

在浏览器开发者工具的 Network 面板中查看 `/api/agent/feedback`：

- `feedback_type: correction` 表示动作纠错建议；`mode: llm` 表示 LLM 生成的文本通过校验，`mode: template` 表示使用本地安全话术。
- `feedback_type: camera_hint` 是镜头/观察提示；这里的 `mode: llm` 仅表示 LLM 选择了固定提示的长短，不代表 LLM 分析了动作。
- 尚未形成持续偏差事件时不会调用纠错生成接口。

## 本地运行与手动查看

1. 按根目录 [README.md](README.md) 配置依赖、`data/models/rtmw_x_384.onnx` 和后端 `.env`。
2. 启动后端和前端开发服务器；修改 Python 代码或规则文件后，重启后端。
3. 页面选择 **133 点：摄像头 / 上传视频**、**山式**、**双臂举起并保持**。
4. 正对摄像头，调整距离，让双肩、双肘和双腕完整入镜；抬起双臂并保持，观察“本次提醒”和“连接状态”。
5. 结束练习后查看“服务器总结”；点击“刷新记录”查看已保存的练习总结。

如果只看到角度，没有纠错，可先看右侧提示和 Network 中 `/api/pose/frame` 的 `analysis`：检查 `reason_codes`、`rule_evaluation.rule_results`、`pending_count` 与 `feedback_allowed`。偏差需要连续确认；模型测得角度本身不会直接触发 LLM。

本地密钥应放在项目根目录 `.env`，不要提交密钥；`.env.example` 只放占位值。

## 自动化检查

在仓库根目录运行：

```powershell
.venv\Scripts\python.exe -m pytest tests/test_online_correction_133.py tests/test_agent_workflow.py tests/test_pose_api_133.py tests/test_memory.py -q
```

前端类型检查与构建：

```powershell
cd frontend
npx tsc --noEmit
npm run build
```

自动化用例检查规则持续确认、帧间隔、LLM 输入/校验、回退和记忆摘要；摄像头权限、实际 RTMW 推理速度和真实画面关键点仍需在本机手动核验。真实人物动作的教学有效性不由合成测试证明。
